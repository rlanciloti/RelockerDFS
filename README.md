# RelockerDFS
RelockerDFS, or RDFS,  is a distributed file storage solution which encrypts and splits files apart before storing the pieces across multiple nodes. RDFS is a TUI (Terminal User Interface) application which means that everything done with the program is done within an interactive terminal window.

## Why RDFS
RelockerDFS is the a solution to private file storage. When storing your data locally on your computer, if your computer is compromised, then the files could easily be stolen. If you choose to store your files in the cloud, then if the cloud device which the files are stored on is compromised, then suddenly your files are in the attackers hands, potentially without your knowledge.
